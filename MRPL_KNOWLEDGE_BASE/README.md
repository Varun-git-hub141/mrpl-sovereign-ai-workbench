# MRPL Knowledge Base

This directory is the runtime location for industrial engineering knowledge used by the Sovereign AI Workbench.

The actual knowledge-base documents are intentionally excluded from this repository.

A deployment may populate this directory with authorized:

- equipment records
- inspection reports
- maintenance records
- P&ID information
- SOPs
- engineering manuals
- previous engineering decisions
- technical datasheets

Only authorized and appropriately licensed data should be used in a production deployment.
